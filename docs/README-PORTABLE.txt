Glyvex AI Suite — ZIP "green" (portable, sin instalador)
========================================================

> **Language:** [Español](#espa-ol)

EN
--

What this is: the same Glyvex AI Suite without installing anything. Extract the
ZIP into a folder and run `glyvexai.exe`. No admin rights needed. It is meant
for users who prefer not to run an installer.

- Manual update: this copy is NOT covered by the in-app auto-updater. To
  update, download the new ZIP from the GitHub Releases page and replace the
  folder. If you trigger the in-app updater, it will download the installer and
  create a NORMAL installation, it will not update this folder.
- Your data is per-user and lives in
  `%LOCALAPPDATA%\Glyvex-AI-Suite\data` — the same folder the installed version
  uses. A green copy and an installed copy on the same user SHARE config,
  database, logs and attachments, and both use backend port 7981: run only one
  of them at a time.
- Windows SmartScreen: the executable is unsigned. If you see "Windows protected
  your PC", click "More info" -> "Run anyway". Tip: extract the ZIP with 7-Zip
  (it does not propagate the web-download mark to the extracted files); with
  the built-in "Extract All" of Explorer the mark propagates and the warning
  shows again.
- Third-party notices: `_up_\THIRD-PARTY-NOTICES.txt`.

ES
--

Qué es: la misma Glyvex AI Suite sin instalar nada. Extrae el ZIP en una
carpeta y ejecuta `glyvexai.exe`. No requiere permisos de administrador. Está
pensado para usuarios que prefieren no usar un instalador.

- Actualización manual: esta copia NO está cubierta por el auto-update de la
  app. Para actualizar, descarga el ZIP nuevo desde la página de GitHub Releases
  y reemplaza la carpeta. Si usas el actualizador dentro de la app, descargará
  el instalador y creará una instalación NORMAL; no actualizará esta carpeta.
- Tus datos son por usuario y viven en
  `%LOCALAPPDATA%\Glyvex-AI-Suite\data` — la misma carpeta que usa la versión
  instalada. Una copia green y una instalación del mismo usuario COMPARTEN
  config, base de datos, logs y adjuntos, y ambas usan el puerto 7981 del
  backend: ejecuta solo una a la vez.
- SmartScreen de Windows: el ejecutable no está firmado. Si aparece "Windows
  protegió tu PC", pulsa "Más información" -> "Ejecutar de todas formas".
  Consejo: extrae el ZIP con 7-Zip (no propaga la marca de descarga web a los
  archivos); con "Extraer todo" del Explorador la marca se propaga y el aviso
  vuelve a aparecer.
- avisos de terceros: `_up_\THIRD-PARTY-NOTICES.txt`.
